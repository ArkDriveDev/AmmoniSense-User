# Ammonisense

**Environmental Monitoring & Compliance System for MENRO**

Ammonisense is a mobile-based environmental monitoring system that enables MENRO inspectors to:
- Detect ammonia levels using Bluetooth-connected ESP32 devices
- Pinpoint exact locations using GPS and grid-based mapping
- Document environmental conditions with photos and notes
- Generate compliance reports and enforcement documentation
- Track historical data for trend analysis

Built for MENRO's environmental protection mandate, Ammonisense transforms mobile devices into environmental monitoring tools.
